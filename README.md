# Cubbe web

The public website, support pages, privacy policy, and terms of use for [Cubbe](https://github.com/jsanchezmir/inside-ios), built with Next.js and deployed to GitHub Pages.

## Local development

```bash
npm install
npm run dev
```

## Pages

- `/` — marketing site
- `/support` — support information
- `/privacy` — privacy policy
- `/terms` — terms of use
